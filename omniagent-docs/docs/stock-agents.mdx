# Stock Agents

Stock agents are ready-made agents shipped with the gem under `OmniAgent::StockAgents`. They bring their own prompt, model settings and tools; your project subclasses one and declares the [structured output](/docs/agent/structured-output) it needs.

## Using a Stock Agent

```bash
rails generate omni_agent:stock_agent InvoiceOcr --from=ocr --fields=invoice_number:string total:number paid:boolean
```

Generates:

```ruby
# app/agents/invoice_ocr.rb
class InvoiceOcr < OmniAgent::StockAgents::OCR
  output do
    string :invoice_number
    number :total
    boolean :paid
  end
end
```

and an optional `app/agents/invoice_ocr/prompt.md.erb`. Edit the `output` block with the full DSL (descriptions, `required: false`, enums, nested arrays and hashes), then run it like any agent:

```ruby
InvoiceOcr.new.run(Pathname("invoice.jpg")).structured_output
# => { invoice_number: "A-1042", total: 120.5, paid: true }
```

A subclass inherits everything from the stock agent — provider, model, `options`, tags, callbacks, tools and prompts — and can override any of it with the usual DSL (`use_model`, `options`, `output`, ...). To replace one of the stock agent's tools, define a tool with the same name under your subclass's `Tools` namespace (e.g. `InvoiceOcr::Tools::Extract`). See [Inheritance](/docs/agent/provider#inheritance) for how `use_model` interacts with an inherited provider.

### Prompts

The stock agent's prompt (shipped inside the gem) is rendered first. If your subclass has `app/agents/<agent_name>/prompt.md.erb`, it is appended after it, so you can add project-specific instructions without copying the stock prompt. The same applies to [run alias](/docs/agent/run-entrypoints) prompt files.

## Available Stock Agents

### OCR

`OmniAgent::StockAgents::OCR` reads photos, scans and PDFs with a vision model (`gpt-4o` by default). Its default output is `{ text: "..." }`, the full text in reading order; declare your own `output` to extract fields instead.

`run` takes one source or an array of them. Several sources are treated as pages of the same document, in order:

```ruby
InvoiceOcr.new.run(Pathname("invoice.pdf"))
InvoiceOcr.new.run([ params[:front], params[:back] ])          # uploaded files
InvoiceOcr.new.run(record.scans.to_a)                          # ActiveStorage attachments
InvoiceOcr.new.run([ "Only the line items", Pathname("page1.png"), URI("https://example.com/page2.png") ])
```

| Source | Sent as |
| --- | --- |
| `Pathname`, `File`, `StringIO`, uploaded files (anything with `read`) | Base64 data URL |
| ActiveStorage attachments and blobs (anything with `download`) | Base64 data URL |
| `URI("https://...")` | Image URL the provider fetches |
| `String` | Text instructions sent with the images |

Files must be PNG, JPEG, GIF, WEBP or PDF; the type is read from the file's bytes, not its name. A plain string is never treated as a file path, so text from your users can't make the agent read files from your server. Pass a `Pathname` to read a file.

PDFs are sent as file parts, which OpenAI supports. Ollama only accepts base64 images, so with Ollama use a vision model (e.g. `llama3.2-vision`) and pass image files, not PDFs or URIs.

### Listing Stock Agents

```ruby
OmniAgent::StockAgents.all          # => [OmniAgent::StockAgents::OCR, ...]
OmniAgent::StockAgents.find(:ocr)   # => OmniAgent::StockAgents::OCR
OmniAgent::StockAgents.find(:nope)  # raises OmniAgent::UnknownStockAgentError
```

## Adding a Stock Agent to the Gem

From the gem repository:

```bash
bin/rake "stock_agent:new[ocr,OCR]"
```

The second argument is only needed when the class name isn't the camelized file name; the task then prints the Zeitwerk inflection to add in `lib/omni_agent.rb`. It creates:

```text
lib/omni_agent/stock_agents/
├── ocr.rb                 # class OmniAgent::StockAgents::OCR < OmniAgent::StockAgent
└── ocr/
    ├── prompt.md.erb      # default prompt
    └── tools/             # optional: OmniAgent::StockAgents::OCR::Tools::*
spec/lib/stock_agents/ocr_spec.rb
```

A stock agent is a regular agent with a few extra class methods:

```ruby
module OmniAgent
  module StockAgents
    class OCR < OmniAgent::StockAgent
      description "Extracts structured data from documents"
      use_model "gpt-4o"

      # Default output, used when the host app doesn't declare its own.
      output do
        string :text, description: "Full text of the document"
      end
    end
  end
end
```

* **`description`**: Human-readable summary of what the stock agent does.
* **`stock_name`**: Name used by `OmniAgent::StockAgents.find` and the generator's `--from`. Defaults to the underscored class name (`OCR` → `:ocr`).
* **`prompts_path`**: Directory with the stock prompt templates. Defaults to `lib/omni_agent/stock_agents/<stock_name>/`.
